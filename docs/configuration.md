# 配置服务

工作台左下角“设置”提供两组互相独立的服务配置。开源包不包含账户、密钥或个人服务地址。先用基础部件模式即可试用本地建模。

## AI + Blender

1. 运行 `安装Blender建模.cmd`，或设置 `XIAOZAO_BLENDER_PATH` 指向自己的 Blender 可执行文件。
2. 在设置中开启大模型建模，填写服务基地址、模型名称和自己的 API 密钥。
3. 选择“自由创造 · AI + Blender”。先用快速模式测试较小的描述，再尝试精细模式或参考图。

服务需支持兼容 Chat Completions 的接口、JSON对象输出和流式回复。根地址会尝试 `/v1/chat/completions`，填入完整 `/v1` 基地址也可。精细复核和图片 / 草图输入需要模型支持图像。各兼容服务能力可能不同，不保证所有代理和模型兼容。

只允许 HTTPS 云地址；本机 `localhost`、`127.0.0.1`、`::1` 可使用 HTTP。本机服务可以留空密钥，但仍需填写模型名称。不要在 URL 中放用户名、密码、查询参数或令牌。

描述、参考图、已有程序、必要错误和精修网格视图会发给该服务，按服务计费。技术修正、外观复核、网络重发会增加请求。Blender 运算在本地；已有程序的项目导入与等比改尺寸不再请求模型。

`config/settings.example.json` 仅为格式参考。如手动配置，可复制到 `data/settings.json` 后填写；推荐直接使用界面。`OPENAI_API_KEY` 可作为未保存配置时的文字服务密钥来源，**本项目不会自动加载 `.env`**。不要将真实配置提交到 Git。

## 专业形象 · Meshy

需要独立 Meshy API 账户和密钥，在设置的专业形象区域填写。文字大模型密钥不能替代该服务密钥。此通道经过模拟接口验证，尚未完成真实服务质量验收。

- 纯文字用于生成几何；若勾选彩色材质，文字模式会额外创建材质任务，可能增加计费。
- 上传参考图时，由图片决定外形，文字用于说明与目标高度。图片接口不会把文字作为结构编辑指令。
- 图片未展示的背面由服务推测。材质、贴图和灯光不等于可打印几何。
- 默认高度120毫米，可明确要求5–250毫米。高度调整在本机等比处理。
- 原始GLB保留源几何和材质；网页目前只显示单色几何。打印几何另外转换为Z轴向上、毫米单位，GLB保留服务原始单位 / 朝向。
- 服装、毛发、配件可能分离或没有厚度。未通过打印检查时保留完整形象及GLB，禁止STL/3MF下载，需要在Blender修复。
- JSON不嵌入GLB。备份时同时下载GLB；跨电脑JSON导入无法仅凭旧编号恢复源资产。
- “继续查询”只恢复已经确认的任务。创建请求结果不确定时不自动重复，先在服务控制台确认。停止等待不会撤销已提交任务或费用。

## 本地基础部件

选择“精确尺寸 · 基础部件”，不需模型服务和 Blender。其范围是界面列出的造型库和二维草图拉伸，不等于任意图片重建。可作安装后的最小试用。

## 文件和备份

| 文件 | 用途 |
| --- | --- |
| `data/settings.json` | 本机明文服务配置，含密钥；不公开 |
| `data/models/` | 个人作品；不公开 |
| `.runtime/` | 描述、图片和建模尝试 / 错误；不公开 |
| `third_party/` | 自行安装的 Blender / 可选模型代码；不随源码分发 |

完整备份请在本机保护好上述目录。对外分享用单件作品的导出入口，并自行检查其中的描述、图片和源程序。
