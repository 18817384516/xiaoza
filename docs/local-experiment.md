# 可选本地 Shap-E 实验

这条路线为实验性CPU生成，未作为0.1.0默认体验或高精度角色方案。不包含第三方源码、模型权重、中文翻译权重，也没有完整的一键安装承诺。当前公开版的建议路线是AI + Blender、基础部件或单独配置的专业形象服务。

`requirements-ai.txt` 仅列出额外依赖，不代表已锁定和验证所有机器的组合。源码中的 `neural_worker.py` 期待以下目录：

- `third_party/shap-e-main/`：Shap-E上游源码及其许可。
- `third_party/CLIP-main/`：CLIP上游源码及其许可。
- `data/ai_models/`：对应的模型与配置；翻译模型位于 `translation/`。

要研究这条路线，请先阅读上游许可和模型卡，自行安装匹配的CPU PyTorch / torchvision及额外依赖，再准备上游代码和检查点。现有 `prepare_generator.py` 从本机上游下载脚本读取地址与哈希；不替用户选择未审阅的第三方代码版本。中文翻译脚本固定了模型仓库版本，但不随源码包分发权重。

所有本地模型文件就绪后，界面才显示实验入口。不要把它的低精度或简化输出当作专业人物雕刻方案。实验路线可能移除分离表面并在警告中说明，与保留完整Meshy源资产的路线不同。
