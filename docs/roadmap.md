# 路线图

以下是待推进方向，不是已交付功能或时间承诺。

- 真实专用3D服务质量评估：记录形象、背面一致性、耗时、费用和打印可修复性。
- 将复杂角色资产更稳妥地转换为打印实体，保留服装 / 配件，提供可解释的修复预览。
- 改善连续曲面、自然五官、手指、衣褶与局部雕刻质量；以外观和用途验收，避免单纯增加面数。
- 增加壁厚、细小结构、悬垂与装配尺寸检查，并进行实际试印。
- 研究更强的程序执行隔离；当前限制不等于安全沙箱。
- 完善Linux / macOS支持和便携安装体验。
- 与真实新手进行可用性测试，验证从想法到导出的完整过程。

0.1.0没有保证任意描述成功、没有工业认证、没有公开多人服务部署，也没有无需配置的专业角色生成模型。
