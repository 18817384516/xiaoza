# 打印与文件

推荐下载3MF，保留明确毫米单位。STL和OBJ不存储可靠的物理单位，切片软件中按毫米读入。

| 格式 | 内容 | 适用路线 |
| --- | --- | --- |
| 3MF | 毫米单位三角网格，无打印机切片预设 | 通过打印检查的作品 |
| STL | 二进制三角网格 | 通过打印检查的作品 |
| OBJ | 几何网格，无预览颜色 / 贴图 | 继续在其他软件处理 |
| JSON | 描述、参数和可恢复程序 / 信息 | 所有路线；Meshy不含原始GLB |
| BLEND / Python | Blender工程与生成的程序 | AI + Blender |
| GLB | 服务返回的原始几何与材质 | Meshy；不代表打印检查通过 |

当前检查包括封闭性、面方向、正体积、连通性和部分明确外廓尺寸；不包含所有孔位、壁厚、悬垂、支撑、机构运动、材料或力学分析。彩色材质和法线贴图无法替代实体细节。模型通过检查也可能存在不可见错误。

在切片软件逐层查看，确认单位、尺寸、首层、最小细节与支撑。装配件先做配合试样；承重件不应只凭网页预览投入使用。项目没有完成实物打印验收。

Meshy资产可能为游戏展示模型，服装分离、毛发面片和开放表面都可能导致打印失败。此时工作台保留完整源文件，标记“打印待修复”，请下载GLB到Blender修复；当前没有保证任意资产自动实体化。
