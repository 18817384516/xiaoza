# 故障排查

## 首次启动很慢 / 安装失败

首次启动需要联网安装Python和Node依赖；Blender安装也需要联网下载较大文件。查看终端中的具体失败。确认Python和Node在PATH中，并确认没有代理或防火墙阻止下载。Blender下载支持继续并校验文件；不建议通过禁用校验处理网络问题。

## 浏览器打开但不能生成

先选择基础部件，输入“方块，长40宽30高20毫米”。如果仍无法完成，查看 `.runtime/server-error.log`；不要直接公开完整日志，它可能包含描述、路径与服务记录。

## 找不到 Blender

运行 `安装Blender建模.cmd`，或将 `XIAOZAO_BLENDER_PATH` 设为完整可执行文件路径后重启服务。Linux / macOS自行安装Blender，或让可执行文件位于PATH中。

## 连接不到大模型

在设置核对基地址、模型名、密钥和额度。云地址使用HTTPS；本机服务可用HTTP。快速模式可先验证文字接口，精细模式与参考图还需要视觉输入。兼容接口不代表所有功能兼容。

已确认的Blender失败任务可点“继续重试”或“继续修复”，沿用记录；不要急于重新描述。若外观精修失败但已有合法模型，系统保留它，并提供复核说明。

## 三轮修正仍失败

点击“继续修复”，保留设计重新检查或修正。也可下载已保存工程在Blender中检查。自相交、零厚度、分离配件、过小交线与明确尺寸冲突都可能造成失败；没有保证任何描述一定成功。

## Meshy显示待修复 / 无法下载打印文件

形象已保存，但未满足打印实体检查。下载原始GLB到Blender处理连接、开放面和厚度；不要将贴图细节理解为打印几何。独立服务密钥、权限和额度需在Meshy账户检查。

“创建结果不确定”意味着云端可能已收到任务。先查服务控制台，避免直接重新生成导致额外收费。“继续查询”仅用于已有确认任务编号。

## 8765端口被占用

先关闭旧工作台或双击 `停止小造.cmd`，确认端口后重新启动。不要结束与本项目无关的应用。浏览器测试使用8766，并且拒绝复用未知的已有服务。

## 发布后的源码不能直接打开网页运行

源码不含 `dist/` 和运行依赖。运行启动脚本让它完成安装与构建。GitHub Pages只提供静态网页，不能代替本机FastAPI与Blender进程。

## 提交问题时

附系统、Python / Node / Blender版本、创作模式、最小描述和必要截图。遮盖密钥、私人图片与文件路径；不要上传 `data/settings.json` 或完整运行目录。
