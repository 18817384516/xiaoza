# 小造 v0.1.0 · 首次开源预览

用中文描述、草图或参考图创作三维模型。大模型编写新的Blender程序，本机运行、检查与导出；同时提供无需密钥的基础部件模式，以及可选Meshy专业形象服务通道。

本版包含工作台源码、公开示例、Windows启动入口、中英文说明、MIT许可证、贡献与安全政策、GitHub问题模板和自动检查。

安装：准备Python3.13和Node.js24，解压源码后运行 `启动小造.cmd`；自由创造还需运行 `安装Blender建模.cmd` 并在设置配置自己的大模型。专业形象模式另需Meshy独立密钥。源码不含账户、Blender、权重或运行依赖。

当前限制：早期版本可能生成失败或造型不符合预期；不能保证专业角色精细度、精密装配或实物打印成功。Meshy通道完成模拟接口验证，尚未完成真实服务质量验收。通过网格检查不等于壁厚、强度和支撑已经验证。

项目面向单人本机使用，不应直接开放公网。详见README、SECURITY与第三方许可说明。
