# 公开示例

这些示例用于体验工作流，不附带任何服务配置、参考图片或个人创作历史。JSON中的公开编号仅为演示，导入时会创建本机新作品。

| 示例 | 内容 | 使用方式 |
| --- | --- | --- |
| bunny | 65毫米高的基础小兔，带底座 | 基础模式，可无密钥导入 |
| bracket | L型支架 | 基础模式，检查孔补偿与配合 |
| gear | 渐开线直齿轮 | 基础模式，先试印啮合间隙 |
| vase | 开口花瓶 | 基础模式，不保证密封 |
| 牛油果椅子 | 高70毫米的造型椅 | 需本机Blender，导入与缩放不需要云服务 |
| U形理线夹-6毫米孔 | 36×20×28毫米，孔径6毫米，孔距18毫米 | 需本机Blender，真实通孔示例 |

工作台底部“导入项目”选择JSON。Blender示例包含完整建模程序，导入会在本机重新运行，只应导入可信项目。公开包不附带BLEND二进制，重建后可从界面下载。

3MF单位为毫米，STL按毫米读取。示例通过网格检查不代表已完成实物打印、壁厚、支撑、承载或装配验收。小兔耳朵、椅腿与凹处尤其需要在切片中确认。

示例公开字段按项目MIT许可提供；第三方素材与服务条款不因此改变。请勿将示例描述当作工业规格或保证。
